# Feste AM – Webseite

Statische Webseite mit Festen und Veranstaltungen in Deutschland
(Volksfeste, Weihnachtsmärkte, Wein- und Stadtfeste).

**Diese Dateien werden automatisch erzeugt** – bitte hier nichts von Hand
ändern. Quelle/Generator liegen separat; bei Datenänderungen wird die Seite
neu generiert und der Inhalt hier ersetzt.
