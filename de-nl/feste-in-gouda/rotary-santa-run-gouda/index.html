Rotary Santa Run Gouda

Sport-Event · Gouda, Binnenstad · 14. Dezember 2026

Wann14. Dezember 2026
WoMarkt (start), Binnenstad, 2801 JG Gouda
ArtSport-Event

Bei der Rotary Santa Run Gouda laufen die Teilnehmer gemeinsam in Weihnachtsmannkostümen für einen guten Zweck, unter anderem zugunsten von Sportvereinen in Gouda und Fitkids Gouda. Start ist auf der Markt. Der Lauf findet am Montagabend, 14. Dezember 2026, statt.
