Run Bournemouth

Sports event · Bournemouth · 10–11 October 2026

When10–11 October 2026
WherePier Approach, Lower Gardens, BH2 5AA Bournemouth
TypeSports event

Run Bournemouth, the Bournemouth Marathon Festival, is a weekend of road running along the Dorset coast. It features a half marathon, a 10k, a 5k and junior races, with routes taking in Boscombe and Bournemouth piers and a finish at Bournemouth Pier Approach.
