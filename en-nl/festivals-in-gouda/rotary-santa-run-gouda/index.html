Rotary Santa Run Gouda

Sports event · Gouda, Binnenstad · 14 December 2026

When14 December 2026
WhereMarkt (start), Binnenstad, 2801 JG Gouda
TypeSports event

At the Rotary Santa Run Gouda, participants run together in Santa costumes for a good cause, including in support of sports clubs in Gouda and Fitkids Gouda. The start is on the Markt square. The run takes place on Monday evening, 14 December 2026.
