Rotary Santa Run Gouda

Sportevenement · Gouda, Binnenstad · 14 december 2026

Wanneer14 december 2026
WaarMarkt (start), Binnenstad, 2801 JG Gouda
TypeSportevenement

Tijdens de Rotary Santa Run Gouda lopen de deelnemers samen in kerstmanpakken voor het goede doel, onder andere ten gunste van sportverenigingen in Gouda en Fitkids Gouda. De start is op de Markt. De loop vindt plaats op maandagavond 14 december 2026.
